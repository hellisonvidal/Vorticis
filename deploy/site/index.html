Como instalar

  1. Baixe o instalador acima e execute. Não precisa de senha de administrador do Windows.
  2. Escolha os módulos. Para usar o banco de dados on-line do escritório, na primeira abertura vá em Conexão com o banco de dados, informe o servidor que o escritório passou, marque Exigir conexão segura (nuvem) e clique em Testar conexão.
  3. Para atualizar, rode o instalador novo por cima: os dados são preservados. O próprio programa avisa quando há versão nova (Ajuda › Verificar atualizações).
